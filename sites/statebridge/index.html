DESIGN RULES

01 / One intent, many carts. A new cart must not silently erase knowledge of a still-unresolved purchase.

02 / No second capture by default. Unknown or pending provider responses block blind retries; reconciliation uses the original order.

03 / Evidence, not confidence theater. A page saying “unpaid” doesn't prove no authorization or capture happened. AI can explain provider facts, never invent a bank state.

04 / Simulation is not Sandbox. This is a product interaction preview. Real PayPal Orders v2 + live LLM + independent merchant reconciliation remain future integration work.
